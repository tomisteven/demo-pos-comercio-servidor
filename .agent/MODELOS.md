# Modelos (Mongoose)

Principales:
| Modelo | Notas |
|---|---|
| `User.js` | Usuarios con roles |
| `Product.js` | Productos, stock, precios, `esFraccionado`, `esCombo`, `codigoBarras`, `mostrarEnCatalogo` |
| `Category.js` | Categorías con color |
| `Sale.js` | Ventas completadas |
| `StockMovement.js` | Movimientos de stock |
| `Customer.js` | Clientes |
| `Order.js` | Pedidos desde catálogo |
| `Budget.js` | Presupuestos |
| `Promotion.js` | Promociones |
| `PurchaseOrder.js` | Órdenes de compra |
| `Expense.js` / `FixedExpense.js` | Gastos |
| `Supplier.js` | Proveedores |
| `Loyalty*` | Fidelización |
| `CalendarEvent.js` | Calendario |
| `SystemConfig.js` | Config global (tienda, paleta catálogo con roles, footer, metas) |
| `AIHistory.js` / `AIFeatureHistory.js` | Historial IA |
| `Investment.js` | Inversiones |
| `Counter.js` | Secuencias |
